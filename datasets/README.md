# Datasets

This directory stores the local dataset copies used by SmartHeart. The datasets remain in their original downloaded or cloned form, while the folder names are standardized to make them easier to reference across the project.

## Current Dataset Map

To make the datasets easier to read and reference, we have renamed them as listed below. Their contents are preserved exactly as they are when downloaded or cloned.

1. `adhd_children_dataset` -> https://ieee-dataport.org/open-access/eeg-data-adhd-control-children
2. `adhd_individuals_gameplay_dataset` -> https://ieee-dataport.org/open-access/focus-eeg-brain-recordings-adhd-and-non-adhd-individuals-during-gameplay
3. `adhd_cognitive_function_dataset` -> https://data.mendeley.com/datasets/6k4g25fhzg/1
4. `neuropsychiatric_imaging_dataset` -> https://openneuro.org/datasets/ds000030
5. `adhd_working_memory_reward_dataset` -> https://openneuro.org/datasets/ds002424
6. `adhd_inhibition_attention_dataset` -> https://openneuro.org/datasets/ds003500
7. `adhd_dualcontrol_dataset` -> https://openneuro.org/datasets/ds005899
8. `cognitive_electrophysiology_dataset` -> https://openneuro.org/datasets/ds006018
